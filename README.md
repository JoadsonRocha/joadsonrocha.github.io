## 🛠️ Tecnologias & Design System

O desenvolvimento deste site foi focado em oferecer a melhor experiência ao usuário (UX) com uma interface extremamente rápida e moderna, sem depender de pesados frameworks na camada de visualização estática:

- **Frontend Core:** HTML5 Semântico, CSS3 Vanilla (Variáveis, Flexbox, CSS Grid).
- **Design & UI:** Efeitos avançados de *Glassmorphism*, paletas dinâmicas com Modo Escuro/Claro integrado e micro-interações.
- **Lógica e Dinâmica:** JavaScript Vanilla para manipulação do DOM e controle de estado global do tema.
- **Responsividade Absoluta:** O site adapta-se a qualquer dispositivo com extrema fluidez.
- **SEO & Acessibilidade:** Configurações de metadados, JSON-LD, tags OpenGraph e suporte robusto a leitores de tela.
