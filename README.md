## 🛠️ Tecnologias & Design System

- **Frontend Core:** HTML5 Semântico, CSS3 Vanilla com variáveis dinâmicas e Flexbox/CSS Grid.
- **Design System:** Efeitos de *Glassmorphism*, paletas dinâmicas com Modo Escuro/Claro integrado e micro-animações.
- **Lógica e Dinâmica:** JavaScript Vanilla para manipulação do DOM, controle de estado global e sistema de filtros de projetos por categoria.
- **Internacionalização (i18n):** Suporte nativo e instantâneo a Português (PT) e Inglês (EN).
- **SEO & Acessibilidade:** Metadados estruturados, Schema JSON-LD, tags OpenGraph e suporte robusto para leitores de tela.
