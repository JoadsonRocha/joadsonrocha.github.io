## 🚀 Sobre o Projeto
Este site foi criado com foco em oferecer uma interface moderna (UI) e uma excelente experiência de usuário (UX). Ele serve como central para baixar meus aplicativos e entrar em contato.

### Destaques do Site:
- **Design Premium e Responsivo:** Adaptado para funcionar perfeitamente em computadores, tablets e celulares.
- **Páginas de Produtos:** Landing pages dedicadas para projetos Desktop (como o MultDownload).
- **Integração:** Links diretos para downloads de executáveis (via GitHub Releases) e redes sociais.

## 🛠️ Tecnologias Utilizadas
- **HTML5** Semântico
- **CSS3 Vanilla** (Uso avançado de variáveis, Flexbox, Grid, Glassmorphism e micro-interações)
- **JavaScript Vanilla** (Para lógica do frontend)

## 📂 Estrutura do Projeto
- `/projetos` - Contém as landing pages específicas dos aplicativos.
- `/style.css` - Sistema de design e estilos globais.
- `/script.js` - Scripts globais e interações da página.
- Páginas principais: `index.html`, `sobre.html`, `contato.html`, etc.
